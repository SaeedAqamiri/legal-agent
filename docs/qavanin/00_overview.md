# ۰۰ — نمای کلی: پلتفرم قوانین به سبک OpenCTI

مسئله: قوانین از چند منبع رسمی می‌آیند (پورتال‌های ملی + فایل‌های کاربر + سامانه داخلی بارای)،
باید **اصل فایل و متن** آن‌ها ذخیره شود، به **گراف دانش سلسله‌مراتبی** (نسخ/ناسخ، قانون مادر، تعارض) تبدیل شوند
و خروجی LLM بدون شواهد وارد دانش قطعی نشود.

## سه لایه

| لایه | نگهدارنده | نقش |
|---|---|---|
| ۱. انبار محتوا | `data/qavanin_store/` (فایل) + Postgres `sources.*` (میتاداتا) | اصل PDF + متن تبدیل‌شده + وضعیت دریافت/استخراج — «منبع حقیقتِ محتوا» |
| ۲. گراف دانش | FalkorDB (مدل کنونیکال پروژه) | نهادها و روابط: سلسله‌مراتب، نسخ/ناسخ، ارجاع‌ها — «منبع حقیقتِ روابط» |
| ۳. خط تولید | کانکتورها + پارسر + LLM + درگاه اعتبار + بازبینی انسان | تبدیل ۱→۲ به‌صورت idempotent و قابل ردیابی |

الگوهای قرضی از OpenCTI (~/opencti):
- **کانکتور خارجی با checkpoint** (`client-python/pycti/connector/opencti_connector_helper.py`) → `sources.sources.checkpoint` + `fetch_runs`
- **مدل اعلانی نوع‌دار** (`schema-attributes.ts`) → مدل کنونیکال + `docs/qavanin/01_graph_schema.md`
- **انبار فایل جدا از گراف** (`database/raw-file-storage.ts`) → `data/qavanin_store/originals/`
- **draft workspace / لایه کاندید** (`modules/draftWorkspace`) → `extraction_jobs.review_status='candidate'` → بازبینی انسان
