# مهارت: ناوبری درون سند

باید تکه‌ی دقیق متن (و صفحه‌ی آن) پیدا شود. رویه:

۱. اگر سند هدف را نمی‌دانید، با `list_documents` کتابخانه را ببینید.
۲. با `list_document_contents` فهرست مواد/فصل‌های سند را بگیرید و بخش مرتبط را انتخاب کنید.
۳. با `find_in_document` عبارت کلیدی را داخل سند جست‌وجو کنید (هر واژه باید در تکه باشد؛ واژه‌های کمتر = نتایج بیشتر).
۴. تکه‌ی پیدا‌شده را با `read_span` کامل بخوانید و فقط همان را cite کنید — page و evidence_id آن دقیق است.
۵. اگر موردی در سند نبود، همین را شواهد امتناع قرار دهید: «در سند X با find_in_document یافت نشد».
۶. زنجیره‌ی پرش: از `get_related` برای ارجاع‌های خروجی/ورودی ماده استفاده کنید.

<=۸ فراخوانی برای این رویه کافی است.
