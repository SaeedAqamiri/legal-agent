# خط‌مشی سبک پرسش — بنچمارک ورزش v1

پرسش‌ها باید شبیه پرسش واقعی مربی، باشگاه‌دار، ورزشکار، مقام فدراسیون، خیر یا وکیل باشند.

در متن سؤال ممنوع است:
- اشاره به Agent / RAG / Graph / Memory / Corpus / Benchmark
- گفتن اینکه «اول سند X را بخوان» یا افشای required_documents / expected_navigation
- دستور ارزیابی مانند «طبق کورپوس جواب بده»

این اطلاعات فقط در gold_answers.jsonl و evaluator_metadata.jsonl نگهداری می‌شوند.
پاسخ Gold هم ابتدا یک پاسخ حقوقی طبیعی است؛ نکات مسیر ناوبری و امتناع در metadata جدا است.
